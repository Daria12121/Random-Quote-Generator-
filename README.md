# Random Quote Generator

**Автор:** Кузубова Дарья

## Описание проекта

Random Quote Generator — это desktop-приложение с графическим интерфейсом (GUI) на Python, которое генерирует случайные цитаты, сохраняет историю всех показанных цитат, позволяет фильтровать их по автору и теме, а также добавлять собственные цитаты. Все данные автоматически сохраняются в JSON-файл и загружаются при следующем запуске.

## Функциональные возможности

1. **Генерация случайной цитаты** — при нажатии на кнопку выбирается случайная цитата из предопределённого списка (8 цитат разных авторов и тем).
2. **История цитат** — каждая сгенерированная или добавленная цитата сохраняется с временной меткой и отображается в списке.
3. **Добавление новых цитат** — пользователь может добавить свою цитату, указав текст, автора и тему.
4. **Фильтрация истории**:
   - По автору (выпадающий список)
   - По теме (выпадающий список)
5. **Сохранение в JSON** — вся история автоматически сохраняется в файл `quotes_history.json` и загружается при запуске.
6. **Проверка ввода** — при добавлении цитаты проверяется, что все поля (текст, автор, тема) заполнены; пустые строки не допускаются.
7. **Удобный интерфейс** — все элементы управления сгруппированы, есть прокрутка для длинного списка истории.

## Технологии

- **Python 3.6+**
- **tkinter** — для создания графического интерфейса
- **random** — для случайного выбора цитат
- **json** — для сохранения и загрузки истории
- **os, datetime** — для работы с файлами и временными метками
